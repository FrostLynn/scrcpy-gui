# scrcpy-gui Developer Notes

Web GUI launcher and device manager for scrcpy on Linux/macOS/Windows.
Stack: Node.js (native ESM, stdlib `node:http`, `node:child_process`, `node:events`), Vanilla JS, Semantic HTML5, CSS Custom Properties. Zero external npm dependencies.
